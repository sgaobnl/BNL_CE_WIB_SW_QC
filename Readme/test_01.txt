● Test01: Serial/TCP/IP Communication Test

  1. Overview

  Test01 validates the communication interfaces between the host PC and the Warm Interface Board (WIB). This test is a prerequisite for all subsequent QC tests, ensuring reliable data exchange pathways are established before proceeding with hardware validation.

  2. Test Objectives

  The test module performs three communication verifications:

  1. UART/Serial Communication - Validates the USB-to-Serial interface by establishing a terminal session with the WIB's embedded Linux system (PetaLinux 2019.1).
  2. TCP/IP Communication - Verifies Ethernet connectivity by sending ICMP echo requests to the WIB's primary IP address (192.168.121.1).
  3. UDP Communication - Confirms network layer functionality by pinging the WIB's secondary IP address (192.168.121.2).

  3. Hardware Requirements

  | Component           | Specification                                         |
  |---------------------|-------------------------------------------------------|
  | Power Supply        | Rigol DP800 Series (12V/3A per channel)               |
  | USB-Serial Adapter  | Silicon Labs CP2105, FTDI FT232, or FTDI FT2232       |
  | Ethernet Connection | Direct or switched connection to 192.168.121.x subnet |

  4. Software Architecture

  The module is structured into eight functions following a modular design pattern:

  | Function               | Description                                        |
  |------------------------|----------------------------------------------------|
  | find_serial_port()     | Scans USB devices for supported serial adapters    |
  | run_uart_test()        | Executes serial login sequence and OS verification |
  | run_ping_test()        | Performs ICMP ping test to specified IP            |
  | retry_test()           | Provides retry/skip/exit handling for failed tests |
  | generate_html_report() | Produces formatted HTML test report                |
  | main()                 | Orchestrates test sequence and resource management |

  5. Test Procedure

  The test executes the following sequence:

  1. Initialize the Rigol DP800 power supply controller
  2. Detect and validate USB-Serial adapter presence
  3. Power on WIB (Channel 1 & 2: 12V, 3A)
  4. Wait 10 seconds for system boot
  5. Execute UART communication test
  6. Execute TCP/IP ping test
  7. Execute UDP ping test
  8. Generate test report and summary
  9. Power off and release resources

  6. Error Handling

  Upon test failure, the operator is presented with three options:

  - Retry (R) - Re-execute the current test
  - Skip (S) - Record failure and proceed to next test
  - Exit (E) - Terminate test sequence with safe power-down

  This approach allows partial test completion when specific interfaces are unavailable while maintaining accurate failure documentation.

  7. Output Artifacts

  | Artifact    | Path                                       | Format     |
  |-------------|--------------------------------------------|------------|
  | Test Report | report/WIB_01_communication_report_01.html | HTML       |
  | Test Data   | rp_dict.log02_wib                          | Dictionary |
  | CSV Records | Via csv_manager                            | CSV        |

  8. Pass/Fail Criteria

  | Test Item | Pass Condition                                  |
  |-----------|-------------------------------------------------|
  | UART      | Successful login and PetaLinux 2019.1 detection |
  | TCP/IP    | 4/4 ping responses from 192.168.121.1           |
  | UDP       | 4/4 ping responses from 192.168.121.2           |
  | Overall   | All three tests pass                            |

  9. Test Duration

  - Typical Duration: 30-40 seconds
  - Warning Threshold: >40 seconds triggers performance warning
